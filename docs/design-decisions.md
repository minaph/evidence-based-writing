# 設計判断

この文書は、`evidence-based-writing` の研究レビューから `SKILL.md` の実務規則へ変換する際に行った採否判断を記録するものです。調査時点は **2026年9月14日**です。

本スキルは、文章品質を禁止語や表面的な文体規則への適合として扱いません。読者が中心命題、根拠、限定条件、論理関係を正確に復元できることを主要な目標とし、研究知見はそのための保守的な編集判断へ変換します。

## 採否判断の原則

研究知見から実務規則を作る際には、単一の実験から直接スタイル規則を導かず、メタ分析、レビュー、複数の実験系列によって比較的安定している現象を優先します。特定の教材、言語、読者集団、実験条件で得られた効果量を、一般の研究文書や技術文書へそのまま外挿しません。

また、研究上の概念をそのままスキルの検査項目にはしません。実行時にモデルが「残す・直す・削る」を判断しやすいことを重視し、理論的な概念を **寄与・関係・範囲・用語・処理負荷**という五つの検査へ変換しました。

品質判断の優先順位は、**正確性と必要十分性 → 論理関係と主張範囲 → 処理しやすさ → 簡潔さ**とします。簡潔化によって証拠、条件、例外、定義、専門的な区別が失われる場合は、簡潔化より正確性を優先します。

## 採用した判断

### 1. 本筋への寄与を検査する

**採用:** 各文が、主張、根拠、定義、限定、論理関係、解釈、手順のいずれかの役割を持つかを確認します。文を削除しても読者の結論、根拠、条件、手順、概念区別、理解可能性が変わらない場合は、削除または統合を優先します。

**根拠となった考え方:** seductive details の研究では、学習目標に不要な興味深い情報が学習を妨げる傾向が、メタ分析を含む複数の研究で報告されています。一方で、効果は大きくなく、具体例や定義まで一律に削る根拠にはなりません。

**設計上の変換:** 「短く書く」「周辺情報は禁止」とはせず、**削除すると何が失われるか**を確認する機能的な検査へ変換しました。理解に必要な例、定義、限定、論理接続は残します。

### 2. 重要情報と情報間の関係を明示する

**採用:** 因果、対比、根拠、条件、帰結、重要性など、本文の判断を左右する関係を読者に推測させすぎないようにします。段落には一つの中心的な役割を与え、表・図・コード・長い列挙が論証を担う場合には、本文で何を見るべきか、結果が何を意味するかを示します。

**根拠となった考え方:** signaling と text structure に関する複数のメタ分析では、重要情報や構造の明示が理解や学習を支える結果が報告されています。ただし、特定の段落形式を常に使うことまで支持する結果ではありません。

**設計上の変換:** 「主張→根拠→解釈→結論」の固定テンプレートは採用せず、**段落の中心的役割と論理関係を追跡可能にする**という水準にとどめました。

### 3. 主張の範囲を限定する

**採用:** 量、頻度、確率、一般性、重要性を表す語では、主張が成立する対象、資料、期間、条件を確認します。根拠に数値がある場合は必要に応じて数値を使い、数値がない場合は対象範囲を狭めます。

**根拠となった考え方:** 言語的な確率・頻度表現は、同じ表現でも受け手による数値解釈のばらつきが大きいことが報告されています。

**設計上の変換:** 「必ず数字を使う」とはせず、**得られる精度だけを使う**ことを原則にしました。「多く」を根拠なく「70%以上」へ置き換えるような、存在しない精度の生成は禁止します。

### 4. 専門語は区別と再利用に寄与する場合に使う

**採用:** 専門語、抽象語、長い語は、それによって意味上の区別が増える場合、または同じ概念をその後安定して参照できる場合に使います。想定読者にとって未知である可能性が高い重要語は初出時に短く定義します。

**根拠となった考え方:** 一般向け科学コミュニケーションの実験では、専門用語が処理流暢性を下げる結果が報告されています。一方で、専門家向け文書では専門語が精密な概念区別を共有し、文章を短く正確にする場合があります。

**設計上の変換:** 「専門語を避ける」という規則は採用せず、**その語が意味上の区別または安定した参照に寄与するか**を判断基準にしました。

### 5. 関連する要素の間へ不要な材料を挟みすぎない

**採用:** 主体と述語、修飾語と修飾対象、原因と結果、条件と帰結、比較対象など、意味的・統語的に強く関係する要素の間へ不要な情報を大量に挟まないようにします。

**根拠となった考え方:** 文処理研究では、長距離の統語依存、記憶からの検索、類似要素による干渉が理解負荷に関係することが長く研究されています。

**設計上の変換:** 「一文は40字以内」のような文字数規則は採用せず、**依存関係を追跡しやすくする**という機能的な規則にしました。長文でも関係が明確なら維持し、短文でも参照関係が曖昧なら修正します。

### 6. 否定表現には弱い規則だけを置く

**限定的に採用:** 同じ意味をより直接的な肯定文で表現でき、対比や除外などの意味を失わない場合には肯定形を優先します。対比、除外、欠如、反証、期待からの逸脱を示す場合には否定を維持します。

**根拠となった考え方:** 否定文が肯定文より処理に時間を要する結果は多くありますが、否定が談話上関連し、情報量を持つ文脈では処理コストが変化することも示されています。

**設計上の変換:** 「否定は禁止」という規則は採用しません。二重否定についても、意味上の差がない場合にだけ直接形へ直します。

## 見送った判断

### given → new を独立原則にする

**見送り:** 既知情報から新情報へ進める傾向は有力な研究領域ですが、構文、焦点、談話文脈、言語による相互作用が大きく、「各文は必ず既知情報から始める」という編集命令に変換すると過剰です。

**代替:** 前文と次文の関係を追跡できるかを「関係」の検査で確認します。

### 受動態、名詞化、副詞、接続詞を形式だけで禁止する

**見送り:** これらの形式にはそれぞれ正当な談話機能があります。形式そのものを検出して置換するより、その文が中心命題を明確にし、範囲を限定し、依存関係を追いやすくしているかを確認する方が本スキルの目的に適合します。

### 一文の文字数・語数に上限を置く

**見送り:** 文長そのものと理解困難性を同一視できず、言語間の語順差もあります。

**代替:** 主体と述語、条件と帰結などの依存関係を追跡しやすいかを確認します。

### 「一段落一主張」を厳密な規則にする

**見送り:** 研究文章では、一つの中心命題に対して限定、反例、複数の証拠を同一段落で扱う必要があります。

**代替:** 一段落に一つの**中心的な役割**を与えます。

### 章末のまとめを必須にする

**見送り:** 既出内容を反復するだけのまとめは情報を増やしません。

**代替:** 結論、含意、次の論点への接続を確定する必要がある場合にまとめを置きます。

### 表・図には必ず導入文を置く

**見送り:** すべての表・図に機械的な導入文を置く必要はありません。

**代替:** 表・図・コード・長い列挙が本文の論証を担う場合に、その直前または直後で、何を見るべきか、その結果が本文の判断をどう変えるかを示します。

## 実務上の割り切り

### 数値スコアを使わない

このスキルは文章を採点する分類器ではなく、文章を実際に改善する編集エージェントとして設計しています。そのため、`informativity = 0.7` のような疑似的な数値評価は採用しません。五つの検査を具体的な編集操作へ直結させます。

### 「新事実を追加するか」だけで文の価値を判断しない

定義、限定、論理接続、解釈、読み方の指示も文章に必要な機能です。各文について、主張・根拠・定義・限定・関係・解釈・手順のいずれかの役割を確認します。

### 曖昧語は二段階で処理する

「多く」「一般に」「可能性がある」などを検出した場合、まず根拠に数値があるかを確認します。数値があれば必要に応じて数値を使い、なければ対象、資料、期間、条件を限定します。根拠がない精度は追加しません。

### 研究レビューと実行仕様を分離する

`SKILL.md` は実行時に必要な判断規則へ絞り、研究レビューそのものは含めません。これにより、スキル本体を短く保ちつつ、設計判断は本ドキュメントで追跡できます。

## 適用上の境界

この設計は、研究文書、技術文書、調査報告、解説、仕様書、提案書などの説明的・分析的文章を主対象にしています。参照した研究の多くは、学習、文章理解、科学コミュニケーション、文処理など個別の条件で行われています。そのため、本スキルは各研究の効果量を一般文章へ直接移すものではありません。

研究知見は、特定の表現形式を機械的に排除するためではなく、**正確性を保ったまま、中心命題・根拠・限定条件・論理関係を読者が追跡しやすくするための保守的な判断根拠**として使用します。

## 判断の要約

| 論点 | 判断 | スキルでの実装 |
| --- | --- | --- |
| 本筋に寄与しない情報 | 採用 | 削除時に何が失われるかを検査する |
| signaling / text structure | 採用 | 重要情報と論理関係を明示する |
| 確率・頻度・一般性の曖昧さ | 採用 | 数値または対象範囲で限定する |
| 専門用語の処理負荷 | 採用 | 区別・再利用に寄与する場合に使う |
| 長距離依存・干渉 | 採用 | 関連要素を追跡しやすく配置する |
| 否定表現 | 限定採用 | 機能がある否定は維持し、不要な迂回表現だけ直す |

| 一段落一主張 | 厳密規則として見送り | 一段落一中心役割とする |
