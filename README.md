# evidence-based-writing

研究文書、技術文書、調査報告、解説、仕様書、提案書などの作成・推敲に使う独立スキルです。中心命題、根拠、限定条件、論理関係を読者が追跡できる文章を目指します。日本語を中心に、正確性と必要十分性を優先し、用語と文章構造を整えます。

## 利用

[SKILL.md](SKILL.md) がスキルの本体です。このリポジトリを利用環境のスキル探索先に配置するか、チェックアウトへのシンボリックリンクを登録してください。他のスキルから使う場合は、Git サブモジュールなどで使用版を固定し、文章作成・推敲の場面で本体を参照できます。

本スキルは、与えられた情報の根拠と条件を保って文章を作成・改善するための指針です。根拠となる資料の収集や、その内容自体の検証は、依頼内容に応じて呼び出し側が担当します。
