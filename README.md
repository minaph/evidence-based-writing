# evidence-based-writing

研究文書、技術文書、調査報告、解説、仕様書、提案書などの作成・推敲に使う独立スキルです。中心命題、根拠、限定条件、論理関係を読者が追跡できる文章を目指します。日本語を中心に、正確性と必要十分性を優先し、用語と文章構造を整えます。

## 背景

このスキルは、**ChatGPT Deep Research による文献調査と設計整理を通じて作成しました**。出発点になったのは、文章術の経験則や禁止語リストを増やすのではなく、文章理解・学習・情報処理などについて蓄積された実証研究を参照すれば、**検証結果と大きく矛盾しにくい、保守的かつ実務的なレポート作成・推敲の方針を示せるのではないか**、という見込みです。

2026年9月14日時点の調査では、単一の実験結果をそのまま一般的な文体規則へ変換することを避け、メタ分析、レビュー、複数の実験系列で比較的安定している現象を優先しました。また、特定の教材や実験条件で観察された効果量を、一般の研究文書・技術文書へそのまま外挿していません。研究知見は「この書き方なら常に良い」という保証ではなく、実務上の編集判断を過度に攻めすぎないための根拠として扱っています。

そのため、`SKILL.md` は研究レビューそのものを収録せず、複数領域の知見と整合しやすい判断だけを、**寄与・関係・範囲・用語・処理負荷**という五つの検査へ落とし込んでいます。文章を短くすること自体や、受動態・名詞化・否定文など特定の形式を一律に排除することは目的にしていません。

研究知見からどの規則を採用し、どの規則を見送ったか、その理由は [docs/design-decisions.md](docs/design-decisions.md) に記録しています。

## 利用

[SKILL.md](SKILL.md) がスキルの本体です。このリポジトリを利用環境のスキル探索先に配置するか、チェックアウトへのシンボリックリンクを登録してください。他のスキルから使う場合は、Git サブモジュールなどで使用版を固定し、文章作成・推敲の場面で本体を参照できます。

本スキルは、与えられた情報の根拠と条件を保って文章を作成・改善するための指針です。根拠となる資料の収集や、その内容自体の検証は、依頼内容に応じて呼び出し側が担当します。
